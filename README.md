# PROplan

PROplan is a mobile pre-production planning application that transforms scattered planning into an organized connected filmmaking workflow.

## Purpose

PROplan is a mobile pre-production workspace for student filmmakers. It brings story development, screenplay writing, dialogue, storyboard planning, locations, cast, and notes into one project so the creative process can move from idea to production in a connected workflow.


## Workspaces

- Story
- Screenplay
- Dialogue
- Storyboard
- Locations
- Cast
- Notes

## Development

Built with:
- JavaScript
- React Native
- Expo
- AsyncStorage
